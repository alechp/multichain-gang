    03 / OPERATOR NOTEBOOK

    Measurement plan

    What the code does

    Reconnect state is keyed to the next expected message sequence, not an L2 block number.

    Why it matters

    A block-height cursor cannot faithfully detect, resume, or explain gaps in the ordered feed.

    Measure this

    • connect → first valid frame, milliseconds
    • receive → verified → inserted, milliseconds
    • gap duration and catch-up throughput

    Failure modes

    • duplicate or skipped message sequence
    • reconnect without buffered early frames
    • validation failure hidden inside “network latency”

    Do not infer

    Timeout and backoff defaults in upstream source are not Robinhood production settings. Validation is a correctness boundary, not an optional speed penalty.
