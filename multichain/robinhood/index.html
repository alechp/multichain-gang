CH-01 · TOPOLOGY

One sequencer,
several control planes

“Permissionless” describes who may use Robinhood Chain and deploy contracts; it does not turn every part into one open committee. A single Robinhood-operated sequencer orders accepted transactions by arrival. Nitro full nodes replay the result. A currently allowlisted BoLD validator set can challenge invalid assertions. Ethereum carries data and settlement, while an eight-seat Security Council controls upgrades.

CH-02 · SIGNAL PATH

A receipt is not
a settlement

An EOA signs for chain 4663—or a smart account submits a UserOperation—then an RPC carries it to the sequencer. Arrival fixes its place. Nitro executes the ordered EVM lane and returns a soft receipt. Later, compressed batch data reaches Ethereum, and later still that Ethereum block finalizes. Applications choose which boundary is sufficient.

CH-03 · ORDER FLOW

MEV after the
gas auction

Paying more gas does not let a later transaction jump an earlier arrival. It does not remove the value of position. The edge moves into transport latency, provider topology, private intent, solver selection, and the first safe reaction to state or oracle updates. The question is no longer only “what did you bid?” but “who saw it, and when did it reach the sequencer?”

DOCUMENTED ABSENCE

No priority gas auction

Execution and data fees remain; they do not buy an earlier FCFS position.

CH-04 · LATENCY

Four clocks,
one user action

“Latency” changes meaning at every boundary. Market input and a sequencer receipt can live below one second. Ethereum posting arrives in minutes; Ethereum finality follows about thirteen minutes later; canonical withdrawal takes roughly seven days plus a final claim. Product safety comes from naming the clock used for each decision.

CH-05 · BENCH

Same game,
different ordering rules

Arbitrage, backruns, liquidations, and launch races change shape across mechanisms. Solana sells bundle position around scheduled leaders. Ethereum routes value through builders and proposers. Bitcoin auctions bytes. Zcash hides the graph. Robinhood Chain is the counterexample: its sequencer does not sell position through priority gas, so arrival latency becomes the bid. The bench compares capabilities—not profitability, safety, or rank.
